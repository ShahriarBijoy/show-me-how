# Composition Patterns and Originality Rules

## Basic structure types

Pick one structure; don't mix too many.

### Workflow

Good for: input -> process -> output, content production, AI workflows, automation chains.

How: input on the left, Xiaohei or a strange machine processing in the middle, output on the right, orange arrows for the main flow.

### System part

Good for: information sources, filters, databases, renderers, a local part of an agent system.

How: draw only 3-5 core modules; Xiaohei takes part in one key action.

### Before / After

Good for: chaos/order, manual/automatic, scattered/gathered, anxious/stable.

How: chaos on the left, stable on the right, orange arrow in between. Characters may be more exaggerated.

### Character states

Good for: user pain points, creator states, too many tools, information anxiety, stuck -> running.

How: 2-4 small states, one short label each.

### Concept metaphor

Good for: content factory, information warehouse, black box in the head, workflow machine, automatic daily report.

How: one big strange object or machine, a little input, one output. Must be memorable.

### Layered method

Good for: methodology frameworks, system layers, capability stacks, content-system layering.

How: stacked boxes, not a formal pyramid; Xiaohei hauls bricks or builds beside it.

### Map route

Good for: idea -> launch, user journey, content handoff path, learning path.

How: one winding path, few nodes, Xiaohei leading a line or walking.

### Mini comic panels

Good for: failure -> success, the real process, complaints, before/after using something.

How: 2-4 small scenes, one action per panel.

## Original-metaphor method

Reinvent the metaphor from the current article every time; never reuse old images.

### Three steps

1. Replace the abstract concept with a physical action: stuck, leaking, getting heavy, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Replace the system structure with a low-tech object: broken machine, cardboard box, drawer, water pipe, mailbox, strange dial, scale, well, ladder, odd workstation.
3. Let Xiaohei carry the action: not standing beside, but stuck in the machine, pulling the wrong line, guarding a gate, carrying, patching, weighing, holding the ladder, recording, stuffing things into some strange device.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water pipe, ball of string, sluice gate, turntable, black box, hole punch, pasta press, clothesline, odd workstation.
- Pick only 1-2 per image; don't pile up.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, recycle.
- The action must serve the core meaning; don't be strange for the sake of strange.

## Anti-copy rules

Don't open or replicate `assets/examples/` by default. Those images are only for style calibration: line density, whitespace, color restraint, Xiaohei's temperament.

Unless the user explicitly says "like this one / replicate this composition / modify this case", don't directly reuse these old compositions:

- Conveyor belt with two breakpoints
- Xiaohei pulling the judgment lever inside a content machine
- Xiaohei becoming a funnel sorting traffic/trust/conversion
- Xiaohei cutting the material fish
- Xiaohei leading the handoff path
- Xiaohei pulling three layers of information sources
- Three Xiaoheis holding a megaphone / building a bridge / opening a door
- Xiaohei stamping the script toolbox
- Xiaohei holding a sign looking at the pitfalls path

Even the same topic needs a new metaphor. E.g. "handoff path" need not be a route; Xiaohei could tie the content's tail to a door handle. "One fish many dishes" need not be a fish; Xiaohei could press one paper ball into several shapes.
