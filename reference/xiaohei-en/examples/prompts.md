# Prompt Examples

These prompts can be copied directly into Codex.

## Plan only

```text
Use $ian-xiaohei-illustrations. Don't generate images yet.
Analyze where the article below deserves illustrations; output a shot list of about 5.
For each image state:
- Which paragraph it follows
- Theme
- Core idea
- Structure type
- What Xiaohei is doing
- Suggested elements
- Suggested labels

<paste article>
```

## Body illustrations for an article

```text
Use $ian-xiaohei-illustrations to generate 4 absurd Xiaohei body illustrations for the article below.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, sparse red/orange/blue handwritten labels.
One core structure per image; no PPT infographics, no cute cartoons.

<paste article>
```

## Illustration strategy for a long article

```text
Use $ian-xiaohei-illustrations to make an illustration strategy for this long article.
Don't illustrate evenly; pick only cognitive anchors: core judgment, input/output loop, before/after, common pitfalls, handoff path.
Default 6-8 images; output the shot list first, don't generate images.

<paste article>
```

## One image for one viewpoint

```text
Use $ian-xiaohei-illustrations to generate one 16:9 body illustration for this viewpoint:

Trust isn't shouted; it's laid down one piece of evidence at a time.

Absurd but clean; Xiaohei must carry the core action.
At most 5 short labels.
```

## Workflow theme

```text
Use $ian-xiaohei-illustrations to generate one image for "processing one raw asset into three kinds of content: traffic, trust, conversion".
No formal flowchart; don't replicate the old one-fish-many-dishes case.
Reinvent a new low-tech metaphor with Xiaohei in the core action.
```

## Edit: remove title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the "Workflow / Flowchart" title and underline in the top-left; keep everything else.
Don't add any text or objects.
```

## Edit: stronger Xiaohei participation

```text
Use $ian-xiaohei-illustrations. This image's direction is right, but Xiaohei feels decorative.
Keep the core meaning and regenerate: make Xiaohei the one actually driving the structure.
Stranger, but still pure white, clean, few words.
```
